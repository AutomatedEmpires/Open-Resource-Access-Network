# ORAN Audit: Actionable Findings Register (2026-11-02)

Companion to [ORAN_COMPREHENSIVE_PLATFORM_AUDIT_2026-11-02.md](ORAN_COMPREHENSIVE_PLATFORM_AUDIT_2026-11-02.md). Revision audited: `e0c9afd`.

## Severity scale

| Severity | Meaning |
| --- | --- |
| **P0** | Active harm or an outage, or a critical exploitable risk; act now |
| **P1** | Blocks the platform from being reliable, safe, or lawful for real users |
| **P2** | Material correctness, trust, or maintainability gap |
| **P3** | Cleanup or low-impact defect |

## Other conventions

**Effort:**

- **S** — under 1 day
- **M** — 1–5 days
- **L** — 1–4 weeks
- **XL** — more than 1 month, or relationship-dependent

**Confidence tag** (at the start of each Finding):

- **[C]** — Confirmed
- **[P]** — Probable
- **[RV]** — Requires Verification

**Restart column:** "Keep" means the fix is needed whether or not the controlled restart recommended in the main report goes ahead. "Moot" means a restart retires the affected code, so only stabilization is warranted.
